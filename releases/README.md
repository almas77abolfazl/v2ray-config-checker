# Releases

این پوشه محل خروجی بیلدهای برنامه است. با اجرای دستور بیلد، فایل‌های نصبی اینجا ساخته می‌شوند:

## بیلد روی سیستم خودت

```bash
npm install
npm run build
```

خروجی‌ها:

| فایل | توضیح |
|---|---|
| `V2Ray Config Checker-<version>-win-x64.exe` | نصب‌کننده (NSIS) — امکان تغییر مسیر نصب و ساخت شورتکات دسکتاپ |
| `V2Ray Config Checker-<version>-portable.exe` | نسخه پرتابل بدون نصب |

نکته‌ها:

- **آیکون**: فایل `assets/icon.ico` با اسکریپت `npm run make:icon` ساخته می‌شود (BMP چندسایز + ورودی ۲۵۶). اگر تغییری در آیکون دادید، ابتدا این اسکریپت را دوباره اجرا کنید. آیکون پنجرهٔ برنامه در زمان اجرا از `assets/icon.png` خوانده می‌شود.
- **بدون ادمین**: برای دور Zدن دانلود ابزار امضا (winCodeSign) که ساخت symlink نیاز به دسترسی ادمین دارد، در `package.json` گزینه `win.signAndEditExecutable: false` تنظیم شده. اگر ترمینال را **Run as Administrator** باز کنید می‌توانید این خط را موقتاً بردارید تا متادیتای نسخه روی فایل exe هم نوشته شود (هیچ امضای دیجیتال انجام نمی‌شود؛ برای امضا به `WIN_CSC_LINK` نیاز دارید).
- هسته `Xray-core` هنگام اولین اجرا از بخش «تنظیمات» دانلود می‌شود، بنابراین در حجم بیلد نیامده.

## انتشار در GitHub Releases

با تگ زدن، ورک‌فلووی `.github/workflows/release.yml` بیلد را روی سرورهای GitHub انجام داده و فایل‌ها را به‌صورت خودکار به ریلیز وصل می‌کند:

```bash
git tag v1.0.0
git push origin v1.0.0
```

> فایل‌های باینری خام در همین پوشه کامیت نمی‌شوند (به `.gitignore` نگاه کنید)؛ محل دانلود برای کاربران، صفحه Releases ریپازیتوری است.
