# نام کانفیگ پروتکل آدرس پورت شبکه / امنیت تاخیر وضعیت اتصال جمنای یوتیوب اکشن

هنوز کانفیگی جمع‌آوری نشده

برای شروع دکمه «جمع‌آوری کانفیگ‌ها» را بزنید یا از پنل کناری یک لیست دستی وارد کنید.

منابع زیر برای جمع‌آوری کانفیگ استفاده می‌شوند. می‌توانید منبع جدید (لینک سابسکریپشن) اضافه کنید.

لینک‌های کانفیگ را (مثل نمونه‌های vless://) اینجا بچسبانید؛ هر خط یک کانفیگ. کانفیگ‌های وارد‌شده ذخیره می‌شوند.

لیست وارد‌شده (0)

اگر دانلود خودکار از GitHub مسدود است، فایل xray.exe را از مخزن XTLS/Xray-core دانلود کنید و از طریق «انتخاب» مسیرش را بدهید.

تعداد بیشتر = تست سریع‌تر ولی مصرف بیشتر CPU/پورت. پیشنهاد: ۶ تا ۸.

برای هر کانفیگ حداکثر این مقدار صبر می‌شود (تست اتصال + بررسی Gemini) بعد نتیجه مشخص می‌شود.

هر ورودی بعد از این مدت منقضی می‌شود و کانفیگ دوباره در جمع‌آوری می‌آید (سرورهای موقتاً خاموش دوباره تست می‌شوند).

۰ کانفیگ

این پروتکل‌ها با هسته Xray قابل تست نیستند. اگر خاموش کنید، در لیست با عنوان «پشتیبانی نشده» می‌آیند و با دکمهٔ «پاکسازی» حذف می‌شوند.

در غیر این صورت کانال‌ها فقط وقتی مستقیم قابلFetch باشند کار می‌کنند.
